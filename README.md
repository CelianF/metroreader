## Données

Les tables de [`metroreader/Data/`](metroreader/Data/) sont tirées de l'[open data Île-de-France Mobilités](https://data.iledefrance-mobilites.fr/), par le générateur [metroreaderdatascript](https://github.com/CelianF/metroreaderdatascript), puis corrigées et enrichies à la main :

| Jeu de données IDFM | Licence |
|---|---|
| [Référentiel des lignes](https://data.iledefrance-mobilites.fr/explore/dataset/referentiel-des-lignes/) | [ODbL](https://doc.transport.data.gouv.fr/le-point-d-acces-national/cadre-juridique/conditions-dutilisation-des-donnees/licence-odbl) |
| [Arrêts et lignes associées](https://data.iledefrance-mobilites.fr/explore/dataset/arrets-lignes/) | [ODbL](https://doc.transport.data.gouv.fr/le-point-d-acces-national/cadre-juridique/conditions-dutilisation-des-donnees/licence-odbl) |
| [Arrêts transporteur](https://data.iledefrance-mobilites.fr/explore/dataset/arrets-transporteur/) | [Licence Ouverte v2.0](https://www.etalab.gouv.fr/wp-content/uploads/2017/04/ETALAB-Licence-Ouverte-v2.0.pdf) |

Base dérivée de jeux sous ODbL, le contenu de `metroreader/Data/` est mis à disposition sous la même licence, l'[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Source : Île-de-France Mobilités.
